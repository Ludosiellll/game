# Форма

Android-приложение для тренировок в зале и бега. Записывает подходы, сам подстраивает веса и повторы под то, что
получилось, ведёт беговой план с таймером и голосом, строит графики силы и выносливости и раскладывает неделю под цель.

## Как поставить на телефон

1. GitHub → **Actions** → последний зелёный запуск **Tests and Android APK** → артефакт **forma-apk**.
2. Распаковать zip, открыть `app-release.apk` на телефоне, разрешить установку из этого источника.
3. Для бега с выключенным экраном разреши «Форме» работу в фоне без ограничений в настройках батареи
   (на экране пробежки есть кнопка, которая открывает настройки приложения).

Обновления ставятся поверх старой версии, только если сборка подписана постоянным ключом (см. «Подпись»).

## Облако (Supabase)

Телефон — главная копия: без интернета всё работает. Если войти в облако (Ещё → Облако), тренировки копируются в
проект Supabase **Training** после каждой тренировки, при запуске и дважды в день в фоне. На новом телефоне достаточно
войти той же почтой и паролем — история, план и прогресс вернутся.

- Схема и права: `supabase/migrations/`. Каждая строка доступна только своему владельцу (RLS), анонимного доступа нет.
- В приложении зашиты адрес проекта и publishable-ключ (`gradle.properties`): они публичные по замыслу Supabase.
- Вход по почте и паролю. В настройках проекта нужно выключить подтверждение почты
  (Authentication → Sign In / Providers → Email → Confirm email): встроенная почта Supabase пишет только участникам
  организации, поэтому без своего SMTP письма друзьям не дойдут.

## Подпись

Release-сборка подписывается ключом из секретов репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
| --- | --- |
| `FORMA_KEYSTORE_BASE64` | файл ключа `.jks` в base64 |
| `FORMA_KEYSTORE_PASSWORD` | пароль хранилища и ключа (alias `forma`) |

Без них CI подписывает одноразовым отладочным ключом и предупреждает об этом в отчёте сборки. Ключ не хранится
в репозитории и заметках.

## Сборка и тесты

Нужен JDK 21.

```bash
./gradlew :core:test                                              # движок: прогрессия, бег, план недели
./gradlew :app:testDebugUnitTest -Proborazzi.test.record=true     # Robolectric, синхронизация, скриншоты в app/build/shots
./gradlew :app:assembleRelease                                    # APK в app/build/outputs/apk/release
```

## Устройство

| Модуль | Что внутри |
| --- | --- |
| `core` | Чистый Kotlin: 1ПМ и RPE, прогрессия по подходам, VDOT и темпы, беговые лестницы, планировщик недели, нагрузка (sRPE), статистика. |
| `app` | Compose UI в четырёх стилях, Room + DataStore, сервис пробежки (foreground, GPS, голос), синхронизация с Supabase (`forma.app.sync`). |
| `supabase/migrations` | SQL, применённый к проекту Training. |

Стек: Kotlin 2.4, AGP 9.4, Compose, Room, DataStore, WorkManager, supabase-kt 3.8 (Auth + PostgREST), Ktor OkHttp.
