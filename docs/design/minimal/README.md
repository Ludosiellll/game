# «Минимализм»: the look Denis picked (30.10)

White (or black) ground, very large bold uppercase titles, hairlines instead of cards, one orange accent, plain short
words. `render.js` draws the five screens with Playwright (`node render.js <out-dir>`); the PNGs are its output.
In the app since 30.10 as the default look (Looks.minimal, Looks.minimalDark): flat sections, uppercase titles, the
workout's prescription in one line, the stadium's lap bars, the plain numbers on Progress.
