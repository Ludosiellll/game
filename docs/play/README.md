# «Форма» в Google Play

> **Отложено 31.10.2026:** Денис решил не публиковать в Play. Ниже — что было подготовлено, на случай если вернёмся;
> ключ загрузки для этого придётся сделать заново.

Что уже готово в репозитории и что нужно сделать руками в Play Console. Проверено 30.10.2026; правила Google
меняются, поэтому всё, что помечено «проверь», стоит сверить с Play Console в момент публикации.

## Что готово

- **Сборка для Play (AAB).** Отдельный тип сборки `play`: без самообновления с GitHub и без разрешений
  `REQUEST_INSTALL_PACKAGES`, `UPDATE_PACKAGES_WITHOUT_USER_ACTION`, `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`
  (Google их не пропустит: обновлять приложение можно только через Play). Обычная сборка с GitHub не меняется.
- **Сборка в GitHub Actions.** «Actions → Tests and Android APK → Run workflow», галочка `play`. После зелёного
  прогона внизу страницы появится артефакт `forma-play-aab` с файлом `.aab`.
- **Жалоба на человека.** В чате (меню «⋯» сверху) и на странице человека: «Пожаловаться», причина выбирается
  касанием (спам, оскорбления, неприличное, другое), сразу можно и заблокировать. Жалобы лежат в Supabase:
  Table Editor → таблица `reports`. Google требует жалобы и блокировку в приложениях с сообщениями.
- **Политика конфиденциальности:** `docs/play/privacy.html`.
- **Удаление аккаунта без телефона:** `docs/play/delete-account.html` (Google требует ссылку на такую страницу).
- **Тексты для страницы в магазине:** `docs/play/listing.md`. **Картинки:** `docs/play/store/`.

## Что сделать тебе

1. **Включить GitHub Pages**, чтобы две страницы выше открывались по ссылке. Репозиторий → Settings → Pages →
   Source: «Deploy from a branch» → ветка `claude/nifty-lamport-9i1c9o`, папка `/docs` → Save. Через пару минут:
   - https://ludosiellll.github.io/game/play/privacy.html
   - https://ludosiellll.github.io/game/play/delete-account.html
2. **Добавить два секрета** из файла `forma-play-upload-secrets.txt` (я пришлю его отдельно): Settings → Secrets and
   variables → Actions → New repository secret. Файл храни у себя, в git его нет.
3. **Аккаунт разработчика.** https://play.google.com/console/signup → «Для себя». Нужны паспорт, телефон и 25 $ разово.
   Проверь: российские карты Google, насколько я знаю, не принимает, нужна карта зарубежного банка на твоё имя.
4. **Создать приложение.** «Создать приложение» → название «Форма» (если занято — «Форма: зал и бег») → язык
   русский → «Приложение» → «Бесплатное» → согласия.
5. **Подпись.** При первой загрузке `.aab` Play предложит Play App Signing: оставь ключ, созданный Google. Свой
   нынешний ключ загрузить нельзя (Google принимает только RSA, а он другой). Поэтому версия из Play не встанет
   поверх версии с GitHub: перед переходом сделай копию в облако, удали старую, поставь из Play, войди — данные вернутся.
6. **Закрытое тестирование.** Новому личному аккаунту Google открывает публикацию для всех только после закрытого
   теста: минимум 12 тестировщиков, 14 дней подряд (проверь цифры в Play Console). Тестирование → Закрытое
   тестирование → создать трек → загрузить `.aab` → список почт тестировщиков → отправить на проверку. Каждый
   тестировщик принимает приглашение по ссылке и ставит приложение из Play. Через 14 дней — «Заявка на доступ к
   рабочей версии».
7. **Раздел «Контент приложения»** (в меню слева «Политика и программы» → «Контент приложения»):
   - Политика конфиденциальности → ссылка на `privacy.html`.
   - Доступ к приложению → «Часть функций требует входа»: создай тестовый аккаунт (почта и пароль) и впиши его
     для проверяющих.
   - Реклама → нет.
   - Возрастные ограничения (анкета IARC) → категория «Другое»; насилия, азарта, покупок нет; «пользователи могут
     общаться» — да; делиться местоположением с другими — нет.
   - Целевая аудитория → 18 лет и старше.
   - Удаление аккаунта → ссылка на `delete-account.html`; в приложении: «Ещё → Облако и резервная копия → Удалить
     аккаунт и данные в облаке».
   - Безопасность данных → ответы ниже.
   - Приложения для здоровья → «Фитнес и активность».
   - Фоновые службы (foreground service) → «Здоровье» и «Местоположение»: пробежка с GPS и счётчиком шагов,
     запущенная пользователем, идёт при выключенном экране. Нужно короткое видео: начал пробежку → уведомление →
     экран выключен → время и круги идут. Загрузи на YouTube «по ссылке» и вставь ссылку.
   - Если спросят про точные будильники: таймер отдыха между подходами должен прозвенеть вовремя при
     выключенном экране, пользователь сам разрешает это в настройках.
8. **Страница в магазине** (Рост → Страница в Google Play): тексты из `listing.md`, иконка 512×512, баннер
   1024×500, скриншоты телефона — всё в `docs/play/store/`. Категория — «Здоровье и фитнес», почта для связи —
   твоя.
9. **Обновления.** Каждая новая версия: Run workflow с галочкой `play` → скачать `.aab` → в Play Console «Создать
   выпуск» в нужном треке → загрузить. Номер версии растёт сам.

## Безопасность данных: ответы

Собирает ли приложение данные — **да**. Все данные шифруются при передаче — **да**. Можно запросить удаление — **да**.
Данные **не передаются** третьим лицам (Google Gemini здесь — обработчик по нашему поручению, это не «передача»).

| Тип данных | Собирается | Обязательно | Зачем |
|---|---|---|---|
| Местоположение → точное | да (GPS-трек пробежки в облачной копии) | нет | функции приложения |
| Личная информация → адрес эл. почты | да | нет (только для облака) | управление аккаунтом |
| Личная информация → имя | да (имя в профиле) | нет | функции приложения |
| Личная информация → идентификаторы пользователя | да | нет | управление аккаунтом |
| Здоровье и фитнес → фитнес | да (тренировки, пробежки) | нет | функции приложения |
| Здоровье и фитнес → здоровье | да (вес, рост, отметки «болею») | нет | функции приложения |
| Сообщения → другие сообщения в приложении | да (сообщения людям, вопросы тренеру) | нет | функции приложения |

Аналитики, рекламы, идентификаторов устройства, журналов сбоев, контактов, фото, платёжных данных нет.

## Чего Play не пропустит и что уже учтено

- Самообновление в обход Play и `REQUEST_INSTALL_PACKAGES` — убраны из сборки `play`.
- Запрос «не экономить батарею» без исключения из правил — убран, вместо него кнопка открывает настройки батареи.
- Целевой API: Play требует Android 16 (API 36) с 31.08.2026, у приложения уже 36.
- Жалобы и блокировка для сообщений — есть.
- Удаление аккаунта в приложении и по ссылке — есть.
